# Recruiter Portfolio

A standalone static portfolio prepared for GitHub Pages. Open `index.html` directly to preview it. No build, installation, or server is required.

Publish the contents of this directory (`index.html`, `style.css`, `script.js`, `portfolio.json`, and `assets/`) at the root of a GitHub Pages repository, or place them in its configured publishing directory. All assets use relative paths, so project repository URLs work too. This directory is independent of the full portfolio application.

The case-study summaries use claims from the supplied HTML. ReCart is labeled a working prototype and ReelDeal a concept/prototype. No measured outcomes or production launch claims were added. Confirm the existing roles and project descriptions before sharing publicly.

The ReCart filtering screen and ReelDeal seat-selection screen are new portfolio demos using illustrative data. ReelDeal uses deterministic rules, not a live AI service. These are not production deployments. Metrics visible inside the supplied original ReCart screenshot are illustrative and unverified.

Google Fonts is optional; local system fonts serve as fallbacks. Case studies remain readable with JavaScript disabled. The two interactive demos and perspective switch require JavaScript. Motion respects reduced-motion preferences. `portfolio.json` provides a machine-readable version of the public professional profile. The shirt icon is from Lucide (ISC license).
